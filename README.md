## Getting Started
The following instructions will guide you to run this project on your computer

## Build with
Node v19.7.0

## Installation
1. Install the node_modules:
```shell
npm install
```

## Start the App
Type the following command to run nodemon and the ExpressServer
```shell
npm start
```


## Database configuration
The database settings are set in the config.js file.

## API-routes
all Routes are configured in ./routes/routes.js

## controller
every interaction with the requests are handled in the ./controllers/controller.js.
In this file every database operation will take place.
